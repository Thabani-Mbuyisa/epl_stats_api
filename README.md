# EPL Stats API

## Short description
This repo contains an API that is used retrieve English Premier League statistics as spreadsheets.

## Technologies
- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- Git/Github

## Setup
### 1. Create virtual environment

python -m venv .venv

### 2. Activate virtual environment

.venv\Scripts\activate

### 3. Install dependencies

pip install fastapi uvicorn sqlalchemy psycopg alembic

### 4. Save dependencies

pip freeze > requirements.txt
